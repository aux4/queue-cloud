# aux4/queue-cloud

aux4.cloud provider plugin for aux4/queue. Adds `cloud` as a `--provider` choice to `aux4 queue`'s work-queue commands -- aux4/queue-sqs pre-configured with scope-prefixed queue names and aux4.cloud defaults.
